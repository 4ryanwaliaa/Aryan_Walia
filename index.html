    A closer look

    From problem to product.

    Two projects, the decisions behind them, and the work you can explore for yourself.

    Automated security testing

    MyPentest

    01
    The problem
    Teams need a practical way to find security issues in their own web applications and understand what to fix.
    02
    My role
    I built the scanning engine and the hosted product, from assessment setup through reporting.
    03
    Key decision
    Require proof of domain control before a scan, then pair findings with evidence and remediation guidance.
    04
    Result
    The public example report shows an assessment of a deliberately vulnerable test app, with grouped findings, evidence and suggested fixes.
    Explore the example report ↗Visit MyPentest ↗

    Open-source intelligence

    MyRecon

    01
    The problem
    A digital footprint is scattered across platforms and public sources, making it difficult to investigate in one place.
    02
    My role
    I built the search services and the interfaces for exploring public identity and infrastructure signals.
    03
    Key decision
    Share lookup services between the API and CLI, and label inconclusive username checks as unknown rather than claiming a match.
    04
    Result
    Live on the web and on Google Play, where it holds a 4.7 star rating. The CLI is open source, with setup instructions and code available to inspect.
    Explore the source ↗Visit MyRecon ↗
